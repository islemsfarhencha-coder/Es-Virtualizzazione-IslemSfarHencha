# Esercitazione: Documentare l'Infrastruttura IT

**Studente:** [Islem SfarHencha]

## Descrizione del Progetto
Questo repository è stato creato per l'esercitazione di infrastrutture IT assegnata dalla prof.ssa Maria Luigia Rauseo. L'obiettivo del progetto è illustrare le basi teoriche e pratiche su cui si fonda il nostro ambiente di lavoro informatico.

La presentazione analizza due aree fondamentali:
1. **Virtualizzazione:** Analisi del ruolo dell'Ipervisore (con focus su Oracle VirtualBox come Hypervisor di Tipo 2) e dei vantaggi derivanti dall'utilizzo delle Macchine Virtuali (isolamento, testing, ottimizzazione hardware).
2. **Workflow di Sviluppo:** L'importanza di GitHub per il backup in cloud, il versionamento del codice tramite commit e la costruzione di un portfolio digitale professionale.
